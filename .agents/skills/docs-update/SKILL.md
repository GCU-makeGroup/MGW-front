# Docs Update

Purpose:
Keep Gachon Group project documentation aligned with the current implementation and workflow.

Workflow:
1. Identify what changed for users, developers, or collaborators.
2. Confirm whether README, AGENTS, or supporting workflow docs need updates.
3. Remove stale statements copied from older projects.
4. Keep commands, commit rules, and doc structure references accurate.
5. If screen work changed, make sure the docs still point to `docs/<screen>/flow.md`, `docs/<screen>/design`, and `docs/<screen>/api` correctly.
6. Note any documentation gaps that still remain.

Output format:
- Docs files updated
- Docs referenced
- Key documentation changes
- Remaining gaps
