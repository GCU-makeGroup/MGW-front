# PR Ready

Purpose:
Perform a final readiness pass before creating a PR.

Checklist:
1. Summarize the intended scope of the change.
2. Confirm the target screen or flow and the docs used.
3. Confirm implementation is complete enough for review.
4. Confirm reviewer findings are addressed or explicitly deferred.
5. Confirm validation results are available.
6. Confirm documentation is updated if needed.
7. Confirm the user has approved moving forward with a PR for the screen.
8. List remaining known risks, gaps, or unresolved doc mismatches.
9. Decide whether the work is ready for PR creation.

Final output:
- Scope summary
- Docs used
- Validation summary
- Reviewer status
- Docs status
- Remaining risks
- PR recommendation
