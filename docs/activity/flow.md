1.png는 Activity 화면이다.

2.png는 1.png에 "view details" 버튼 두개가 있는데, 그것을 눌렀을 뜨는 화면이다. 즉 activity 상세 화면이다.

3.png는 2.png에서 "Join This Group" 버튼을 눌렀을 때 뜨는 화면이다. 1인으로 참여할지 어떤 그룹으로 참여할지를 나타낸다.

4.png는 3.png에서 그룹으로 참여시 어떤 그룹으로 참여하는지 선택하는 것을 나타낸다.

5.png는 Activity에 참여 성공한 화면이다.

6.png는 Activity에 참여 실패한 화면이다.

7.png는 1.png에서 "+" 버튼을 눌렀을 때 나오는 화면이다. 즉 Activity 추가화면이다.

8.png Activity 생성이 완료된 화면이다.

9.png는 1.png 오른쪽 위 "My Activity" 버튼을 눌렀을 때 나오는 My Activities 화면이다. Joined 탭에서 내가 참여한 Activity 목록을 보여준다.

10.png는 9.png의 Created 탭을 눌렀을 때 나오는 화면이다. 내가 만든 Activity 목록을 보여주고, 각 항목의 연필 버튼은 수정 진입점으로 사용한다.

11.png는 9.png 또는 10.png의 Activity 항목을 눌렀을 때 나오는 상세 화면이다. 상세 정보와 공유 버튼, "Join KakaoTalk Group" 버튼을 보여준다.

12.png는 9.png 또는 10.png의 "+" 버튼을 눌렀을 때 나오는 Activity 생성 화면이다.
